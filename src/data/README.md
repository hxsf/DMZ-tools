# 游戏资料

本目录保存带来源的游戏资料，供解锁跟踪、打印计算和需求清单使用。当前包含 175 个物品（111 项物品 / 材料、32 把武器、32 份手册）、95 个打印配方、5 个能力定义和 32 个武器手册解锁关系。`catalog.coverage` 仍为 `sample`：本批覆盖所查来源的普通打印配方与手册目录，不表示覆盖所有版本、永久升级或其他游戏物品。这里不保存用户库存、个人进度或网页原文；图片文件另存 `src/assets/third-party/`。

`catalog.ts` 聚合这些数据；各条记录通过本项目定义的稳定 ID 关联。ID 不冒充游戏内部 ID。类型、运行数据和用户存档分离，更新资料不改变用户记录。

这些记录未宣称覆盖全游戏，也未全部经过当前客户端实测。`reported` 只表示来源有记载，`unknown` 明确保留未知，`conflicting` 保存相互矛盾的来源声明。客户端武器截图只用于名称与分类核对，不用来导入价格或个人解锁状态。

## 来源与日期

来源标题、链接、类型、查阅日期、确知的发布日期 `publishedOn` 和更新时间 `updatedOn` 位于 [`sources.ts`](sources.ts)。本批查阅日期为 2026-11-05。官方 FOB 指南发布于 2026-10-09，官方武器文章与等级表发布于 2026-10-19；它们描述首发前后机制，未标明独立更新时间，因此 `updatedOn` 为 `null`。

DMZHub 普通配方及手册目录未给出明确的发布或更新日期，两项均保留 `null`；配方目录注明 Season 0，但未给出补丁版本。已有单页中明确标注的更新时间分别保留：镇静剂吸入器、小型安全背包、防辐射药为 2026-10-20，侦察无人机为 2026-10-21，三条既有中间材料配方为 2026-10-23，SANG 9mm 手册详情为 2026-10-30。无标签日期与 Added 日期不推断为正式发表日期。

DMZTracker 配方表的数据更新时间为 2026-11-02，CODMunity 配方规划页为 2026-10-26，DMZ Codex 两份手册页为 2026-10-28，All Things How 手册文章为 2026-10-21；这些日期存入 `updatedOn`，`publishedOn` 保留 `null`。不能由查阅日期或更新时间推断适用的游戏版本。

客户端截图来源 `source:user-weapon-screenshots` 使用 `kind: "in-game"`，只证明截图中可见的名称和分类；未显示客户端构建号。社区中文站仍属于社区来源，不能因为使用中文就标为官方译名。

原文、图像、商标等版权归原权利人；登记来源不改变其许可。应用资料只整理所需名称、分类、对应关系和数值事实，不复制网页正文。当前 143 张真实游戏图片通过 `images.ts` 按物品 ID 映射，手册复用对应枪图。逐图出处、原图链接与许可状态分别见 [DMZHub（119 张）](../assets/third-party/items/dmzhub/ATTRIBUTION.md)、[DMZTracker（23 张）](../assets/third-party/items/dmztracker/ATTRIBUTION.md)和 [MW4Field（1 张）](../assets/third-party/items/mw4field/ATTRIBUTION.md)。配方来源 `dmztracker.com` 与图片来源 `dmztracker.gg` 分别登记，不混为同一 URL。

其他物品优先按[官方简体等级表](https://www.callofduty.com/cn/zh/blog/2026/10/call-of-duty-modern-warfare-4-ready-for-launch-progression-prestige)与英文表的等级、奖励位置对应，补充明确的官方名称。未取得官方对应的名称以社区或项目来源区分，旧译名继续保留；不能把等级奖励中的成品当成配方奖励。`zhCNOrigin: "official"` 表示官方文字来源，不单独代表游戏实测；具体依据由 `sourceIds` 区分。更换译名不改变物品 ID、配方 ID 和用户进度。

## 需要继续核对的字段

1. **每次产量**：95 项配方仍全部为 `unknown`。网页列表的“+1”、可打印次数及计算器假设均不能证明产量；用户需显式填写单次产量，随制作目标保存，不改公共事实。
2. **现金费用**：未明确确认不收现金，所有普通配方的 `cash` 暂为 `null`。手册售价、撤离奖励、截图中的购买价格不互相替代，也不用于推算制作费用。
3. **材料打印升级**：精制／史诗材料打印能力的 `unlock` 仍为未知。开发参考中的升级费用、打印次数和前置关系尚未集成，不能据此自动授予能力或声称已支持升级跟踪。
4. **7 项材料成本冲突**：起爆器（`recipe:detonators`）、爆破炸药（`recipe:door-breacher-charge`）、防辐射药（`recipe:radiation-blockers`）、自救包（`recipe:self-revive-kit`）、防弹插板箱（`recipe:armor-box`）、炸弹小飞机（`recipe:bomb-glider`）、一次性降落伞（`recipe:disposable-parachute`）。保留各来源的材料组合，不按多数或页面日期自动选定；确认前计算器阻止据其生成确定的材料需求。
5. **解锁与材料覆盖**：缺少获取条件不影响手动标记；缺少某个材料的配方不代表游戏里不可制作。资料范围受本次来源与版本限制，新增内容继续按证据补充。

## 稀有度与图片底色

`rarities.ts` 记录 2026-11-05 [DMZHub 配方目录](https://dmzhub.gg/3d-printer)中的产出物与材料 `rarity` 字段，再由 `items.ts` 合并为可选的 `Item.rarity: Fact<ItemRarity>`；同一材料的重复声明已核对一致。共 107 项：普通 16、精制 25、稀有 23、史诗 19、传奇 16、终极 8，覆盖全部 95 项配方产出以及 12 项其他材料。

四类基础资源没有收录固定稀有度，保留深灰资源图标底色。32 把枪械和 32 份手册尚未收集到可靠的固定稀有度，保持中性背景；不能从关联手册、截图名称颜色或枪械配件数量推断枪械品质。缺失不会被自动当作普通品质，冲突声明也不着色。

色相采用 DMZHub 同一目录的 `rarities` 配色和具名物品详情的徽标：普通 `#98989A`、精制 `#87B951`、稀有 `#4190C8`、史诗 `#9E94F6`、传奇 `#F89442`、终极 `#FC4F32`；中文标签对应其简体目录，属于社区来源。本站将颜色与白色混合为浅色渐变，并保留底部色条；这是本站展示样式，不声称复刻客户端精确色值。图片的悬停提示和替代文本同时说明稀有度，避免只用颜色传达含义。

只更改图片区域的 CSS，不改图片文件、原图归属、整行卡片背景或用户解锁状态。公共 `ItemImage` 同时用于配方解锁、打印目录、已选物品和材料汇总。
