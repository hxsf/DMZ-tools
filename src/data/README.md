# 游戏资料样本

本目录保存手工整理的游戏资料，用于解锁跟踪与检验 `src/types/` 的数据契约。当前包含 82 个物品（18 个材料／装备、32 把武器、32 份手册）、10 个打印配方、5 个能力定义和 32 个武器手册解锁关系。目录整体仍标记为 `sample`：打印配方仅为样本；手册覆盖本次查阅的 DMZHub 32 条手册目录，不表示覆盖所有游戏版本。没有用户库存、个人进度、图片或网页原文。

`catalog.ts` 聚合这些数据；各条记录通过本项目定义的稳定 ID 关联。ID 不冒充游戏内部 ID。类型、运行数据和用户存档分离，更新资料不改变用户记录。

## 样本覆盖

- 基础配方：绷带、医疗包、中型背包。
- 等级配方：镇静剂吸入器；任务配方：侦察无人机；搜刮配方：小型安全背包。
- 可打印中间材料：生物材料、硬质合成材料、防弹织物。
- 来源冲突：防辐射药，保留两组材料成本及各自来源。
- 武器手册：覆盖 [DMZHub Weapon Manual Collection](https://dmzhub.gg/weapons/manuals) 本次查阅时列出的 32 条记录。`weapons.ts` 集中保存名称、武器分类及对应关系，`items.ts` 和 `manuals.ts` 据此生成物品与解锁映射，保留原有 M4、Kastov 762、Sang 9mm 的 ID 和额外来源。

手册名称和武器名称分别保存，中文手册名为项目说明性译名。DMZHub 的 `SANG 9mm` 条目标题未写 Manual，但详情页明确标为 Weapon Manual 并关联 Sang 9mm；原实测来源的 `Manual: Sang 9mm` 保留为别名。具体获取条件可以缺省，不影响用户手动标记是否解锁；已知通则只供参考。

这些记录不代表全量数据库，也未经过当前游戏内实测。`reported` 只表示来源有记载；`unknown` 明确保留未知；`conflicting` 保存相互矛盾的来源声明。成本、产量、配方解锁和打印能力分别记录证据。手册分类来自社区目录，未用官方武器总数推算手册数量。

## 来源与日期

来源标题、链接、来源类型、查阅日期、确知的发布日期 `publishedOn` 和更新时间 `updatedOn` 位于 [`sources.ts`](sources.ts)。官方 FOB 指南发布于 2026-10-09，官方等级表发布于 2026-10-19；它们描述首发前后机制，未标明独立更新时间，因此 `updatedOn` 为 `null`。DMZHub 所引用的单条配方页属于 Season 0。

DMZHub 单条配方页明确标注的更新时间已存入 `updatedOn`：镇静剂吸入器、小型安全背包、防辐射药为 2026-10-20，侦察无人机为 2026-10-21，三条中间材料配方为 2026-10-23。页面还显示一个无标签的日期，本批不将它推断为首次发表日期，`publishedOn` 保留 `null`。

DMZTracker 页尾的数据更新时间为 2026-11-02，CODMunity 配方规划页为 2026-10-26，DMZ Codex 两份手册页为 2026-10-28，All Things How 手册文章为 2026-10-21；这些日期同样存入 `updatedOn`，`publishedOn` 保留 `null`。不能由查阅日期或更新时间推断资料适用的游戏版本。

DMZHub 手册目录没有给出明确的发布或更新日期，两项均为 `null`，查阅日期为 2026-11-05。SANG 9mm 手册详情页明确标注 Last updated 为 2026-10-30，独立登记该来源；其 Added 日期不作为明确的发布日期，`publishedOn` 保留 `null`。

中文名称优先使用官方中文指南，并用 `zhCNOrigin` 区分官方译名、社区译名和项目整理名称。社区别名用于检索，不作为关联键。原权利人对其文章、美术、名称等内容的权利不因本项目记录事实与来源链接而改变；本目录只整理所需名称、分类、对应关系和数值事实，没有复制第三方文章、描述或图标，也不声明获得这些内容的再分发授权。外部原文存档仍按 `docs/external/` 的约定处理。

## 中文名称核对

[官方简体武器文章](https://www.callofduty.com/cn/zh/blog/2026/10/call-of-duty-modern-warfare-4-launch-multiplayer-operators-weapons-equipment-create-a-class)可以对应当前全部 32 把武器。31 把采用武器小节标题作为中文区域的名称；官方保留英文的 M4、JOKR 等沿用原名。`official` 仅表示官方发表过该名称，不表示已经核对当前客户端 UI。

同篇文章的 ISO Nightshade、Oden、Signal 50 存在不同写法，分别以“ISO夜影”“奥登”“西格诺50”为展示名，“ISO幽夜”“欧登”“信号50”为别名。JOKR 的“标枪导弹”也保留为别名。SANG 9mm 被官网写成“尚武9毫米机匣”，该异常名称暂只作别名，展示仍回退英文。完整映射位于 `weapons.ts`。

[官方简体等级表](https://www.callofduty.com/cn/zh/blog/2026/10/call-of-duty-modern-warfare-4-ready-for-launch-progression-prestige)与英文表按等级和奖励位置对应，补充了镇静剂吸入器（3 级）、结构合金（43 级）、高韧度纤维（53 级）、防辐射药（11 级救护包内容）和侦察无人机（19 级装备包内容）的官方用名。侦察无人机在 46 级装备包中另写为“斥候无人机”，保留为别名。旧社区译名继续保留，不改变物品 ID、配方和存档。电子传感器等尚无明确对应的中文名称继续标为社区译名。

## 需要继续核对的字段

1. **每次产量**：此次来源没有明确证明，全部记为 `unknown`。网页列表的“+1”不能当作产量；DMZTracker 的材料产出 1 是其计算假设。未来计算打印次数时必须先取得可信产量，不能默认为 1。
2. **现金费用**：未明确确认不收现金，所有配方 `cash` 暂为 `null`。手册名单不填逐条现金奖励；官方所述一般撤离奖励与社区条目售价不是同一字段，不能互相替代，更不能当作制作或购买费用。
3. **材料打印升级**：已记录配方要求的精制／史诗材料打印能力，但升级费用、多次打印进度和全部前置尚未核实，能力的 `unlock` 为未知。
4. **防辐射药成本**：两个来源组不同，后续必须核对当前游戏卡片；不能按多数来源或较新页面自动选定数值。
5. **等级奖励性质**：获得成品材料或装备不代表获得配方。记录配方解锁时仅使用明确标为配方的奖励。
6. **材料是否能制作**：样本中没有某种材料的配方，不代表游戏里不可制作；资料集合只覆盖本批样本。

上述限制使这批资料适合类型设计和引用验证，暂不适合直接宣称“准确可打印数量”。
